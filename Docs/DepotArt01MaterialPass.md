# DEPOT-ART-01 — Material study atlas (first pass)

## Why
The latest reviewed Unity screenshot confirms that DEPOT-VISUAL-09's single ground silhouette is readable, but warehouse, roof, road and concrete remain broad flat colored faces. More rearranged quads are unlikely to reach the art-quality target.

## Delivered
- Deterministic, compact 320×64 five-swatch texture generated by `DepotSurfacePatternAtlas`: asphalt aggregate, concrete with understated joint, roof seam material, vertically ribbed siding, and a plain neutral swatch.
- Colors are restrained neutral greyscale multipliers so the existing authored navy/steel vertex colors remain the final palette; this is a **replaceable visual material study**, not a photoreal texture set.
- Bind per-quad UVs to matching materials on the existing *one-mesh, one-material* `DepotYardBlockoutView`. No change to building geometry, level states, camera or gameplay.
- Ensure the runtime texture is created with the renderer and released when the component disables/destroys. No separate objects are spawned per wall or per frame.
- Editor menu `LogistiCore → Depot → Export Surface Material Study` writes the same atlas as `Assets/Game/Art/Depot/Generated/DepotMaterialStudy01.png` only with an explicit user confirmation. This is for optional artwork review and editing. **The PNG is not yet in the GitHub PR**; Unity must run the export for it to exist.
- Unit contracts assert swatch sizes and differences, valid UV bounds and complete mesh vertex UV assignment.

## Review instructions
1. With Unity closed and a clean worktree, switch to `feature/depot-art-01-surface-material-atlas` (stacked draft based on DEPOT-VISUAL-09). Do not discard the locally created `DepotPrototype.unity` or old stashes.
2. Open `DepotPrototype` in Unity; Play mode off; set Editor Preview Stage to `StorageOperational`.
3. Examine the building's roof seams, facade corrugation, pavement grain, concrete apron and overall legibility at 16:9 and a landscape mobile resolution. These subtle patterns should not become coarse visual noise.
4. Compare against `ReservedParcel` and `ActivationReady`. No owned building should be visible in an unverified runtime account.
5. Run `DepotPrototypeVisualTests` and the whole EditMode suite, then Android/iOS screenshots/performance checks. **None of these have run in this workspace.**
6. Optionally export and review the PNG; after review, commit PNG and Unity-generated `.meta` on a separate art PR with provenance. The source atlas is authored entirely in the project and has no stock/downloaded imagery dependencies.

## Not delivered / quality gate
This is a working **prototype material pass**, not finished bespoke illustration/sprite production. Curated photographic or hand-painted texture sources, UV continuity on larger facade sections, site gatehouse/fence asset pack, region variations and art QA remain future tasks. No Firebase, shipments, contract, money, saves, scene/build profiles or `main` changes.
